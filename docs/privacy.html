개인정보처리방침 (Privacy Policy)

시행일: 2026년 10월 7일

'sjcompany' (이하 '회사')는 사용자의 개인정보를 매우 중요하게 생각하며, "정보통신망 이용촉진 및 정보보호"에 관한 법률 및 구글 플레이(Google Play)의 사용자 데이터 정책을 철저히 준수하고 있습니다.

1. 수집하는 데이터 및 권한 항목

본 앱('말로 하는 냉장고')은 원활한 서비스 제공을 위해 아래와 같은 권한 및 데이터를 수집/사용합니다.

  • 마이크(RECORD_AUDIO) 권한: 사용자의 음성 명령을 인식하여 식재료 이름과 소비기한을 텍스트로 변환하기 위해 필수적으로 사용됩니다. 변환된 음성 데이터는 서버에 영구 보관되지 않으며, 타인에게 제공되지 않습니다.
  • 광고 식별자(ADID): 맞춤형 광고 제공(Google AdMob) 및 앱의 사용성 통계 분석을 위해 비식별화된 상태로 수집될 수 있습니다.

2. 개인정보의 수집 및 이용 목적

수집된 데이터는 다음의 목적을 위해서만 활용됩니다.

  • 사용자 음성 명령에 기반한 식재료 데이터베이스(DB) 자동 기록, 수정, 삭제 기능 제공
  • 앱 내 맞춤형 광고 게재 (Google AdMob 연동)

3. 개인정보의 제3자 제공 및 위탁

회사는 원칙적으로 사용자의 개인정보를 외부에 제공하지 않습니다. 단, 핵심 기능 제공을 위해 아래의 검증된 외부 API 및 플랫폼을 활용합니다.

  • 음성 인식 API: 사용자 음성의 텍스트 변환 처리 (데이터는 명령어 처리 직후 즉시 폐기되며, AI 학습 모델에 사용되지 않습니다.)
  • Google AdMob: 앱 내 광고 송출을 위한 비식별 데이터 처리

4. 데이터 보관 및 파기 절차

본 앱은 식재료 데이터를 원칙적으로 사용자의 기기(Local Storage) 내부 또는 개인화된 데이터베이스에 저장합니다. 사용자가 앱을 삭제하거나 데이터 초기화를 진행할 경우, 저장된 모든 식재료 데이터는 즉시 복구 불가능한 상태로 영구 파기됩니다.
